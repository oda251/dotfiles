# バックエンド言語の採用トレンド 2024-2026: JetBrains State of Developer Ecosystem

## 調査概要

- 2024 版: 23,262 名対象、2024 年 5-6 月実施（[InfoWorld 報道](https://www.infoworld.com/article/3625652/javascript-is-still-number-one-jetbrains-report.html)）
- 2025 版: 24,534 名対象（194 か国）、2025 年 4-6 月実施（[JetBrains Research Blog](https://blog.jetbrains.com/research/2025/10/state-of-developer-ecosystem-2025/)）

## 使用率（2024, 全回答者）

「使用している」言語の割合。複数回答。

| 言語 | 2024 | 前年比 |
|------|------|--------|
| JavaScript | 61% | — |
| Python | 57% | +3pp |
| Java | 46% | — |
| TypeScript | 37% | +3pp |
| Go | — | +1pp |
| Rust | 11% | +1pp |
| Kotlin | — | — |

- ソース: [InfoWorld "JavaScript is still number one"](https://www.infoworld.com/article/3625652/javascript-is-still-number-one-jetbrains-report.html)
- Go・Kotlin の具体的な使用率パーセンテージは上記記事に記載なし。Go は +1pp、Rust は +1pp と報じられている
- Rust 11% は 2018 年の 2% から成長（同ソース）

## 5 年間の成長推移

| 言語 | 2017/2018 頃 | 2024 | 変化幅 |
|------|-------------|------|--------|
| TypeScript | 12%（2017） | 35% | +23pp |
| Python | 32%（2017） | 57% | +25pp |
| Rust | 2%（2018） | 11% | +9pp |
| Java | 47%（2017） | 46% | -1pp |

- ソース: [InfoWorld "JavaScript is still number one"](https://www.infoworld.com/article/3625652/javascript-is-still-number-one-jetbrains-report.html)
- 注: InfoWorld 記事では TypeScript を 35% と記載。別箇所で 37% とも記載されており、「使用率」と「5 年推移チャート」で集計基準が異なる可能性がある

## 使用率（2025）

2025 版レポートはインタラクティブチャートで提供されており、WebFetch ではチャート内の数値を抽出できなかった。以下は本文テキストから確認できた定性的情報のみ。

- TypeScript: 過去 5 年間で最も劇的に使用率が伸びた言語（[JetBrains Tools and Trends](https://devecosystem-2025.jetbrains.com/tools-and-trends)）
- Rust, Go, Kotlin: 緩やかだが着実に市場シェアを拡大し続けている（同ソース）
- PHP, Ruby, Objective-C: 長期的な下落傾向が継続（同ソース）
- Go: プロフェッショナル開発者 220 万人がプライマリ言語として使用。5 年前の約 2 倍。セカンダリ含め 500 万人超（[JetBrains GoLand Blog](https://blog.jetbrains.com/go/2025/11/10/go-language-trends-ecosystem-2025/)）

具体的なパーセンテージ（2025 版）は **未確認**。

## Language Promise Index

JetBrains が独自に算出する指標。成長安定性（growth stability）、採用モメンタム（adoption momentum）、ユーザーロイヤルティ（user loyalty）の 3 要素を組み合わせ、今後 1 年間で使用拡大が見込まれる言語を特定する（[JetBrains Tools and Trends](https://devecosystem-2025.jetbrains.com/tools-and-trends)）。

### 2024 版ランキング

TypeScript, Rust, Python が「undisputed leaders（明確なリーダー）」とされる（[JetBrains Blog 2024](https://blog.jetbrains.com/team/2024/12/11/the-state-of-developer-ecosystem-2024-unveiling-current-developer-trends-the-unstoppable-rise-of-ai-adoption-leading-languages-and-impact-on-developer-experience/)）。

具体的なスコアや順位の数値は **未確認**。

### 2025 版ランキング

| 順位 | 言語 |
|------|------|
| 1 | TypeScript |
| 2 | Rust |
| 3 | Python |
| 4 | Go |

- ソース: [JetBrains GoLand Blog](https://blog.jetbrains.com/go/2025/11/10/go-language-trends-ecosystem-2025/)（Go が 4 位と明記）
- 最も成長ポテンシャルが高いとされるのは TypeScript, Rust, Go。成熟期（maturity plateau）に達したとされるのは JavaScript, PHP, SQL（[JetBrains Tools and Trends](https://devecosystem-2025.jetbrains.com/tools-and-trends)）
- Kotlin の順位は **未確認**
- Java の順位は **未確認**
- 具体的なスコア値は **未確認**

## 報酬上位の言語（2024）

高報酬と関連付けられた言語（上位順）: Scala, Go, Kotlin, Rust。次いで C++, Shell, Java, Python（[JetBrains Blog 2024](https://blog.jetbrains.com/team/2024/12/11/the-state-of-developer-ecosystem-2024-unveiling-current-developer-trends-the-unstoppable-rise-of-ai-adoption-leading-languages-and-impact-on-developer-experience/)）。

2025 版では Scala 開発者がプライマリ言語使用者のわずか 2% でありながら最高報酬層の 38% を占めるとされる（[JetBrains Research Blog](https://blog.jetbrains.com/research/2025/10/state-of-developer-ecosystem-2025/)）。
