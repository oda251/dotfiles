# cpl: 直前のコマンドと出力をクリップボードへコピー

## 目的

同じターミナル（= 同じ herdr ペイン）で直前に実行したコマンドと、その出力をまとめてクリップボードへコピーする zsh コマンド `cpl` を追加する。issue 起票や AI への貼り付けで、スクロールして手で選択する手間をなくす。

## 前提

- シェルは herdr のペイン内で動く（`HERDR_ENV=1` / `HERDR_PANE_ID`）。スクロールバックは `herdr pane read <pane> --source recent-unwrapped --format text` で取得する
- プロンプトは starship の3行ブロック（空行 / パワーライン行 / `❯ <コマンド>`）。`❯` 始まりの行をコマンド行の境界として使う
- herdr 外では機能させず、エラー終了する

## 振る舞い

```mermaid
flowchart TD
    A[cpl 実行] --> B{herdr ペイン内?}
    B -- No --> E[エラー終了・クリップボード非実行]
    B -- Yes --> C[herdr pane read でペインのテキストを取得]
    C --> D[fc -ln -2 -2 で直前コマンド文字列を取得]
    D --> F{末尾から走査して<br/>直前コマンド文字列と一致する ❯ 行}
    F -- 一致あり --> G[その行を対象コマンド行にする]
    F -- 一致なし --> H{cpl 以外の ❯ 行が末尾側にあるか}
    H -- あり --> G
    H -- なし --> E
    G --> I[対象行の次行〜次プロンプト直前を出力として切り出す]
    I --> J[コマンド行を '$ ' に正規化し末尾の空行・装飾行を除去]
    J --> K{クリップボードコマンドあり?}
    K -- Yes --> L[クリップボードへ書き込み + サマリを stderr へ]
    K -- No --> M[stdout へ出力]
```

## 要件チェックリスト

抽出ロジックは純関数 `__cpl_extract <直前コマンド文字列>`（ペインテキストを stdin で受け、`$ <コマンド>` + 出力を stdout へ）としてユニットテストする。

- [ ] R1 基本形: `❯ echo hello` + 出力2行 + 次プロンプトブロック → `$ echo hello` + 出力2行を返す
- [ ] R2 出力なし: `❯ pwd` の直後に次プロンプト → `$ pwd` の1行のみを返す（末尾に空行を残さない）
- [ ] R3 対象行が末尾でない: 対象コマンド行の後ろに `❯ cpl` が続く場合、`cpl` 行以降を含めない
- [ ] R4 cpl 連投: 末尾側の `❯ cpl` を読み飛ばし、その前の非 cpl コマンドを対象にする（履歴一致なしの場合）
- [ ] R5 出力中の偽プロンプト: 出力行が `❯ ` で始まっていても、履歴のコマンド文字列と一致する行を優先して対象を誤らない
- [ ] R6 プロンプト行なし: `❯` 行が1つも無いテキストでは非0終了し、何も出力しない
- [ ] R7 直接確認: herdr 外（`HERDR_ENV` 未設定）では `cpl` がエラーメッセージを出して非0終了し、クリップボードを触らない
- [ ] R8 直接確認: 実ペインで `cpl` を実行すると、クリップボードに `$ <コマンド>` + 出力が入り、コピー行数のサマリが表示される

## インターフェース

| 項目 | 内容 |
|---|---|
| コマンド | `cpl`（引数なし） |
| 配置 | `dot_zsh/copy-last.zsh` を `dot_zsh/plugins.zsh.tmpl` から `source_cache_script` で読み込む |
| テスト | `scripts/test-copy-last.zsh`（zsh のみ。`zsh scripts/test-copy-last.zsh` で実行） |
| 環境変数 | `CPL_PROMPT_MARK`（既定 `❯`）、`CPL_SCAN_LINES`（既定 2000） |
| クリップボード | WSL: `clip.exe` / macOS: `pbcopy` / Wayland: `wl-copy` / X11: `xclip` の順で検出。無ければ stdout |
