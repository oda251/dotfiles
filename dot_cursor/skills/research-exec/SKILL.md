## 手順

### 1. 計画ファイルの読み込み

引き継がれた計画ファイル（`docs/.tasks/*-research-*.md`）を読み、現フェーズの未完了タスクを特定する。

### 2. 収集の並列起動

同一フェーズ内のタスクを並列でサブエージェントに委譲する。起動時にステータスを `⬜` → `🔵` に更新。

サブエージェントに計画ファイルのパス + タスクID + 保存先 + **research-gather** スキルを使うよう指示する。

収集結果の保存先: `docs/.research/{date}-{topic}/`（エージェントごとにファイルを分ける）

タスク完了時にステータスを `🔵` → `✅` に更新。

### 3. ドキュメント作成

現フェーズの全タスクが `✅` になったら、サブエージェントに収集結果ディレクトリ + 出力先 + **research-write** スキルを使うよう指示する。

### 4. レビュー

サブエージェントにドキュメントパス + **research-review** スキルを使うよう指示する。

- **十分** → 次フェーズへ（またはチェーン完了）
- **不足あり** → 不足観点を新タスクとして計画ファイルの現フェーズに追加し、ステップ 2 に戻る

### 5. フェーズ遷移

次フェーズがあれば並列起動する（ステップ 2 に戻る）。

全フェーズ完了で終了。
