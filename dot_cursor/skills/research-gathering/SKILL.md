## 手順

### 1. 収集の実行

research-planning で列挙したリソースごとにサブエージェントを起動する。**オーケストレーターは収集しない。** 収集とファイル書き出しを同じエージェントが行うことで、コンテキスト圧縮による消失を防ぐ。

サブエージェントへの指示:

```
以下のリソースにアクセスし、[調査テーマ] に関連する情報を抽出せよ。
- リソース: [URL or ファイルパス]
- 抽出すべき情報: [具体的な観点]
- 出力形式: 事実のリスト。各項目に必ずソースを併記すること（URL、ファイルパス:行番号、ドキュメント名+セクション等）
- 保存先: [エージェントごとに割り当てたファイルパス]
- ソースのない情報は記録しない。確認できなかった項目は「未確認」と明記する
```

### 2. 収集結果のファイル構成

保存先ディレクトリ: `docs/.research/{date}-inv-{topic}/`

エージェントごとにファイルを分ける（競合防止）:

```
docs/.research/2026-03-25-inv-websocket-vs-sse/
├── 01-react-docs.md
├── 02-mdn-websocket.md
└── 03-sse-spec.md
```

各ファイルの形式:

```markdown
# [リソース名]

- 事実1（[ソースURL or ファイルパス:行番号]）
- 事実2（[ソースURL or ファイルパス:行番号]）
```

### 3. 収集結果の確認

- 列挙したリソースすべてにアクセスしたか
- 各事実にソースが付いているか
- 調査テーマに対して十分な情報が集まったか

不足があれば追加で収集する。

## 次のスキル

→ **investigation-writing** を呼べ。収集結果ファイルのパスを引き継ぐ。
