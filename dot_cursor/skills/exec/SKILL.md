## 手順

### 1. ドメイン判別とガイドライン読み込み

現フェーズの見出し（`exec-dev` / `exec-research`）からドメインを判別し、対応するガイドラインを読む:
- `exec-dev` → `~/.claude/references/dev-exec-guideline.md`
- `exec-research` → `~/.claude/references/research-exec-guideline.md`

### 2. タスク消化

ガイドラインに従って現フェーズのタスクを実行する。起動時にステータスを `⬜` → `🔵` に更新。タスク完了時に `🔵` → `✅`。

## 次のタスク判断

現フェーズ完了後、次の未完了フェーズの種別に応じてスキルを呼ぶ。タスクファイルのパスを引き継ぐ:
- `plan-*` → **plan** を呼べ
- `exec-*` → **exec** を呼べ

全フェーズ完了の場合:
- 親タスクファイルの対象フェーズ内タスクを `🔵` → `✅` に更新する
- 親に次の未完了フェーズがあれば、種別に応じてスキルを呼ぶ。親タスクファイルのパスを引き継ぐ
- 親がさらに親を持ち全完了 → 再帰的に上へ
- root の全フェーズ完了 → ゴール達成をユーザーに報告する
