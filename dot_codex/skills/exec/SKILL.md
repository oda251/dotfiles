## 手順

### 1. ドメイン判別

計画ファイルのファイル名から種別（dev / research）を判別する。

### 2. ガイドライン読み込み

種別に応じたガイドラインを読む:
- `dev` → `~/.claude/references/dev-exec-guideline.md`
- `research` → `~/.claude/references/research-exec-guideline.md`

### 3. タスク消化

計画ファイルの現フェーズの未完了タスクを特定し、ガイドラインに従って実行する。

同一フェーズ内のタスクは並列でサブエージェントに委譲する。起動時にステータスを `⬜` → `🔵` に更新。タスク完了時に `🔵` → `✅`。

### 4. フェーズ遷移

現フェーズの全タスクが `✅` になったら、次フェーズのタスクを並列起動する（ステップ 3 に戻る）。

### 5. メタファイル更新

全フェーズ完了で、メタファイルの現ステップを `✅` に更新する。

次の未完了ステップがあれば → **plan** を呼べ。メタファイルのパスを引き継ぐ。
全ステップ完了 → 終了。
