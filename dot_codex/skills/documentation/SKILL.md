---
name: documentation
description: 計画・設計・運用・手順のドキュメントを新規作成/更新するときに使う
---

**手順:**
1. ユーザーにドキュメントの種別（計画 / 設計 / 運用 / 手順）と対象を確認する
2. `docs/` ディレクトリが存在しなければ作成する
3. 種別に応じたサブディレクトリに配置する
   - 計画: `docs/planning/`
   - 設計: `docs/design/`
   - 運用: `docs/operations/`
   - 手順: `docs/procedures/`
4. 既存ドキュメントがあれば内容を確認し、差分を更新する
5. 新規作成の場合は以下のテンプレート構成に従う
   - タイトル（作成日時を含める）
   - 概要
   - 詳細（本文）
   - 備考（必要に応じて）
