## 手順

### 1. 計画ファイルの読み込み

`docs/plans/*.md` を読み、現フェーズの未完了タスクを特定する。

### 2. タスクの並列起動

同一フェーズ内のタスクを並列でサブエージェントに委譲する。起動時にステータスを `⬜` → `🔵` に更新。

サブエージェントにタスク内容 + **dev-impl** スキルを使うよう指示する。

### 3. レビュー

タスク完了（`🔵` → `🟡`）のたびに、フェーズ全体の完了を待たずレビューする。

サブエージェントに変更内容 + **code-review** スキルを使うよう指示する。

- **指摘なし** → `🟡` → `✅`
- **指摘あり** → `🟡` → `🔵`、修正サブエージェントを再起動。振る舞いの変更を伴う指摘にはテスト追加を先にやるよう指示を含めること

### 4. フェーズ遷移

現フェーズの全タスクが `✅` になったら、次フェーズのタスクを並列起動する（ステップ 2 に戻る）。

全フェーズ完了で終了。
