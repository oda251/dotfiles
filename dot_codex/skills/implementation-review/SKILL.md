## 手順

### 1. レビュー

別エージェントを起動し、以下を指示する:

```
以下の変更をレビューせよ。
- 変更ファイル: [ファイルパス一覧]
- 変更の意図: [何を実現するための変更か]
- 観点:
  - 対象言語のガイドライン（~/.claude/references/{lang}.md, {lang}-{framework}.md）があれば従う
  - テストがある場合: ~/.claude/references/testing-guideline.md に従う
- 問題があれば具体的な修正案を示すこと
```

### 2. 判断

- **指摘なし** → 全テスト pass・ビルド確認して完了
- **指摘あり** → implementation に戻す。振る舞いの変更を伴う指摘にはテスト追加を先にやるよう指示を含めること

### 3. タスク進捗の更新

計画ファイル（`docs/plans/*.md`）が引き継がれている場合、タスクのステータスを更新する:
- レビュー開始時: `🔵` → `🟡`
- 指摘あり（差し戻し）: `🟡` → `🔵`
- 指摘なし（完了）: `🟡` → `✅`

## タスク消化

計画ファイルが引き継がれている場合、以下のルールでタスクを消化する:

- 同一フェーズ内のタスクは並列実行する
- `🟡`（レビュー待ち）のタスクがあればその都度レビューする（フェーズ全体の完了を待たない）
- 現フェーズの全タスクが `✅` になったら次フェーズのタスクを並列起動する

## 次のスキル

- **指摘あり** → **implementation** に戻る
- **`🟡` タスクあり** → レビューする
- **現フェーズ全 `✅`・次フェーズあり** → 次フェーズの全タスクを並列起動:
  - `[setup]` → **implementation**
  - `[tdd]` → **tdd-impl**
- **全フェーズ完了** → **完了**（チェーン終端）
