## トリガー

research-gathering から遷移してきたとき。

## 手順

### 1. ドキュメント作成

収集結果ディレクトリ（`docs/.research/{date}-inv-{topic}/`）内の全ファイルを読み、調査ドキュメントを作成する。

- **documentation スキルのフォーマット規則に従うこと**（命名、出典ルール、テンプレート）
- ファイル名: `docs/{date}-inv-{topic}.md`
- 各情報にインラインで出典を付ける（末尾まとめ禁止）
- **出典は収集結果ファイル内の原本ソース（URL、ファイルパス:行番号等）をそのまま使うこと。** 収集結果ファイルへの参照（`docs/.research/...`）は出典にならない
- 出典のない情報は **（未検証）** と明記する

### 2. ドキュメント作成の委譲

リソースが5つ以上の調査では、サブエージェントにドキュメント作成を委譲する:

```
以下の収集結果を元に調査ドキュメントを作成せよ。
- documentation スキルに従ってフォーマットすること
- 入力: [収集結果ディレクトリのパス]（中の全ファイルを読むこと）
- 出力先: docs/{date}-inv-{topic}.md
- 各情報にインラインで出典を付けること。収集結果内の原本ソース（URL等）をそのまま使い、収集結果ファイルへの参照は出典にしないこと
```

サブエージェントの成果物は必ずレビューしてからユーザーに返す。

### 3. セルフチェック

```
□ 各情報にインラインで出典を付けたか？
□ 出典なしの情報に（未検証）を付けたか？
□ 関連ドキュメントへのリンクを付けたか？
□ 詳細を捏造していないか？
□ 調査テーマに対して網羅的か？
```

## 次のスキル

→ **investigation-review** を呼べ。作成したドキュメントのパスを引き継ぐ。
