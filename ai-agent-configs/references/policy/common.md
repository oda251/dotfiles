# 共通ポリシー

言語・レイヤー非依存のコーディングルール。

## 型安全

- `any`（TS）/ `Any`（Python）等の型消去を使わない。`unknown` で受けて narrowing する

## 外部境界

- システム境界（外部API、ユーザ入力、環境変数、ファイルI/O等）ではバリデーションし、型付きの内部表現に変換する
- 環境変数は起動時にスキーマで検証し、型付きの設定オブジェクトとしてアクセスする。生の `process.env` / `os.environ` 等を内部で直接参照しない
- 内部コード間の受け渡しでは再バリデーションしない。境界で一度変換すれば十分

## データモデルと DTO

- DTO を明確に定義する
- モデル層（DB スキーマ等）を SSOT とし、DTO はモデルから派生させる
- モデルと DTO を独立に定義しない。モデルの変更が DTO に自動的に反映される設計にする
