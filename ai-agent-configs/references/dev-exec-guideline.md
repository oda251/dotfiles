# Dev 実行ガイドライン

## フェーズの実行

同一フェーズ内のタスクは Agent Teams で並列実行する。同一ファイルへの同時書き込みが発生しないようタスク分割時に注意すること。

各タスクについて:

1. サブエージェントに計画ファイルのパス + タスクID + **dev-impl** スキルを使うよう指示する
2. 完了後、サブエージェントに計画ファイルのパス + タスクID + 変更内容 + **dev-review** スキルを使うよう指示してレビューする
3. **指摘なし** → タスク完了
4. **指摘あり** → サブエージェントに計画ファイルのパス + タスクID + レビュー指摘 + **dev-impl** スキルを使うよう指示して再起動。ステップ 2 に戻る

フェーズ全体の完了を待たず、タスクごとにレビューする。
