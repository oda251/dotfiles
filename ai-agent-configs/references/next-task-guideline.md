# 次のタスク判断ガイドライン

plan / exec の完了後に共通で使用する。

## 手順

### 1. 現ファイルの確認

現タスクファイルに次の未完了フェーズ（⬜ を含むフェーズ）があるか？

- **ある** → そのフェーズの種別で呼ぶ。タスクファイルのパスとフェーズ番号を引き継ぐ:
  - `plan-*` → **plan**
  - `exec-*` → **exec**

### 2. 親ファイルへの移動

現ファイルの全フェーズが完了（全タスク ✅）の場合:

1. 親タスクファイル（frontmatter の parent / parent-phase）の対象タスクを `🔵` → `✅` に更新する
2. 親の次の未完了フェーズを探す

### 3. 親の未完了フェーズの処理

- **フェーズ内に 🔵（展開済み・子ファイルリンクあり）のタスクがある** → 子ファイルに移動し、その中の未完了フェーズから再開（ステップ 1 に戻る）
- **フェーズ内に ⬜ のタスクのみ** → そのフェーズの種別で呼ぶ。親タスクファイルのパスとフェーズ番号を引き継ぐ

### 4. 再帰

親も全フェーズ完了の場合、さらに親へ移動する（ステップ 2 に戻る）。

### 5. root 完了

親を持たない root タスクファイルの全フェーズが完了 → ゴール達成をユーザーに報告する。
