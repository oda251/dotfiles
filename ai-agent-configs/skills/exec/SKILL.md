## 手順

### 1. ドメイン判別とガイドライン読み込み

タスクファイルのファイル名から種別（dev / research）を判別し、対応するガイドラインを読む:
- `dev` → `~/.claude/references/dev-exec-guideline.md`
- `research` → `~/.claude/references/research-exec-guideline.md`

### 2. タスク消化

タスクファイルの現フェーズの未完了タスクを特定し、ガイドラインに従って実行する。

同一フェーズ内のタスクは並列でサブエージェントに委譲する。起動時にステータスを `⬜` → `🔵` に更新。タスク完了時に `🔵` → `✅`。

全タスク完了後、次フェーズがあれば続けて並列起動する。

### 3. 完了処理

全フェーズ完了で、親タスクファイルの対象タスクを `🔵` → `✅` に更新する。

## 次のタスク判断

親タスクファイルの次の未完了タスクのプレフィックスに応じてスキルを呼ぶ:
- `plan-*` → **plan** を呼べ。親タスクファイルのパスを引き継ぐ
- `exec-*` → **exec** を呼べ

親タスクの全タスク完了の場合:
- 親がさらに親を持つ → その親の対象タスクを `🔵` → `✅` に更新し、再帰的に次を判断
- root の場合 → ゴール達成をユーザーに報告する
