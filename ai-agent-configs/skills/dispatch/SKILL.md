## ステータス

| 表記 | 意味 |
|------|------|
| `⬜` | 未着手 |
| `🔵` | 実行中 |
| `✅` | 完了 |

## 手順

### 1. 次のタスクの特定

タスクファイルとフェーズ番号が引き継がれている場合、対象フェーズに直接進む。

引き継がれていない場合、以下の「次のタスク判断」で探索する。

### 2. ステータス更新

対象タスクを `⬜` → `🔵` に更新する。

子ファイルを持つタスク（🔵 + リンク）の場合、子ファイルに移動して未完了フェーズから再開する。

### 3. スキル呼び出し

フェーズ見出しの種別に応じてスキルを呼ぶ。タスクファイルのパスとフェーズ番号を引き継ぐ:
- `plan-*` → **plan**
- `exec-*` → **exec**

## 次のタスク判断

### 1. 現ファイルの確認

現タスクファイルに次の未完了フェーズ（⬜ を含む、またはタスク行がない未展開フェーズ）があるか？

- **ある** → ステップ 2（ステータス更新）に進む

### 2. 親ファイルへの移動

現ファイルの全フェーズが完了（全タスク ✅）の場合:

1. 親タスクファイル（frontmatter の parent / parent-phase）の対象タスクを `🔵` → `✅` に更新する
2. 親の次の未完了フェーズを探す

### 3. 親の未完了フェーズの処理

- **フェーズ内に 🔵（展開済み・子ファイルリンクあり）のタスクがある** → 子ファイルに移動し、その中の未完了フェーズから再開（ステップ 1 に戻る）
- **フェーズ内に ⬜ のタスクのみ** → ステップ 2（ステータス更新）に進む

### 4. 再帰

親も全フェーズ完了の場合、さらに親へ移動する（ステップ 2 に戻る）。

### 5. root 完了

親を持たない root タスクファイルの全フェーズが完了 → ゴール達成をユーザーに報告する。
