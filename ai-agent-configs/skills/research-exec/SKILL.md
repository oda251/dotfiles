## 手順

### 1. 計画ファイルの読み込み

引き継がれた計画ファイル（`docs/.tasks/*-research-*.md`）を読み、現フェーズの未完了タスクを特定する。

### 2. 収集の並列起動

同一フェーズ内のタスクを並列でサブエージェントに委譲する。起動時にステータスを `⬜` → `🔵` に更新。

サブエージェントに計画ファイルのパス + タスクID + 以下を指示する:

```
以下の観点について調査せよ。
- 調査観点: [タスク内容]
- 出力形式: 事実のリスト。各項目に必ずソースを併記すること（URL、ファイルパス:行番号、ドキュメント名+セクション等）
- 保存先: [エージェントごとに割り当てたファイルパス]
- WebSearch のスニペットを事実として記録するな。必ず WebFetch でページ本文を読み、本文に記載されている情報のみ記録すること
- 1リソースごとに即ファイルに書き出せ。まとめて書くな
- ページ内に関連する内部リンク（同一ドメイン）があれば積極的に追え
- ソースのない情報は記録しない。確認できなかった項目は「未確認」と明記する
```

タスク完了時にステータスを `🔵` → `✅` に更新。

収集結果の保存先: `docs/.research/{date}-{topic}/`（エージェントごとにファイルを分ける）

### 3. ドキュメント作成

現フェーズの全タスクが `✅` になったら、サブエージェントに **research-write** スキルを使うよう指示する。

### 4. レビュー

サブエージェントに **research-review** スキルを使うよう指示する。

- **十分** → 次フェーズへ（またはチェーン完了）
- **不足あり** → 不足観点を新タスクとして計画ファイルの現フェーズに追加し、ステップ 2 に戻る

### 5. フェーズ遷移

次フェーズがあれば並列起動する（ステップ 2 に戻る）。

全フェーズ完了で終了。
