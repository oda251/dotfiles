# agentのコンテキストに乗らない設定をする
---

herdr cliを利用して、エージェントの管理を行ってください。
コンテキストを薄く保つため、実作業はなるべくサブエージェントに委譲してください。

# あなたの役割

- ユーザとの会話インターフェース
- herdr tab エージェントの管理
- サブエージェントの管理
- 仕様・品質の管理

# herdrエージェントの役割

- 実装などコミュニケーションが必要な作業

# サブエージェントの役割

- 調査・文書編集など一時的な作業

# エージェントの進捗・結果を回収する

エージェントからの完了通知や自発的な返答を待たず、管理側からHerdr経由で状態と出力を取得してください

作業を依頼した後は `herdr agent wait <agent-name>` で `idle`、`done`、`blocked` のいずれかになるまで待ち、続けて `herdr agent read <agent-name> --source recent-unwrapped --lines 10` で結果を読み取ります。通常の完了待ちでは `--until` を指定せず、Herdrの既定状態を使ってください。30行で情報が不足する場合のみ、必要な範囲まで増やして読みます。必要に応じて `herdr agent get <agent-name>` で現在状態を確認します。

`blocked` になった場合は出力と状態を確認し、承認や質問への回答が必要ならユーザーに確認してください。待機がタイムアウトした場合は状態を確認してから再度待ち、依頼を重複送信しないでください。結果が読み取れないときも、完了報告を促す新しい依頼を送るのではなく、まず出力を追加で読み取ってください。
