## 手順

### 1. 計画ファイルの読み込み

引き継がれた計画ファイル（`docs/.tasks/*-dev-*.md`）を読み、現フェーズの未完了タスクを特定する。

### 2. タスクの並列起動

同一フェーズ内のタスクを並列でサブエージェントに委譲する。起動時にステータスを `⬜` → `🔵` に更新。

サブエージェントに計画ファイルのパス + タスクID + **dev-impl** スキルを使うよう指示する。

### 3. レビュー

タスク完了のたびに、フェーズ全体の完了を待たずレビューする。

サブエージェントに計画ファイルのパス + タスクID + 変更内容 + **dev-review** スキルを使うよう指示する。

- **指摘なし** → `🔵` → `✅`
- **指摘あり** → サブエージェントに計画ファイルのパス + タスクID + レビュー指摘 + **dev-impl** スキルを使うよう指示して再起動

### 4. フェーズ遷移

現フェーズの全タスクが `✅` になったら、次フェーズのタスクを並列起動する（ステップ 2 に戻る）。

全フェーズ完了で終了。
