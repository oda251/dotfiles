# Anti-Hallucination Protocol

## 判断ツリー（必須）

```
質問タイプ?
├── 技術的事実                 → ctx7 docs or 公式ドキュメントで確認してから回答
├── 一般的事実                 → WebSearch で確認してから回答
├── ファイル内容               → Read で確認してから回答
├── コードの挙動               → Read + トレースしてから回答
└── 確認不能                   → 「わかりません」と明言
```

## 信頼度宣言（必須）

| レベル | 基準 | 回答フォーマット |
|--------|------|------------------|
| **HIGH** | ツールで確認済み、2つ以上のソース | `[source] によると: ...` |
| **MEDIUM** | 単一の信頼できるソース | `[source] に基づくが、要確認: ...` |
| **LOW** | 記憶のみ、未検証 | `...と認識しているが、確認が必要` |
| **UNKNOWN** | データなし | `わかりません。検索しますか？` |

## 検証ワークフロー

### Step 1: 主張の種類を特定

| 主張の種類 | 検証ツール |
|------------|------------|
| 技術的事実 | `ctx7 docs` or 公式ドキュメント |
| 一般的な事実 | `WebSearch` |
| 特定のURL | `WebFetch` |
| ファイル内容 | `Read` |
| コードパターン | `Grep` |

### Step 2: 検証を実行

回答前に:
1. 適切なツールを使用
2. 結果を精読
3. 関連情報を抽出
4. バージョン制約を確認

### Step 3: 回答にソースを明記

```
# 良い回答
React 18.2 のドキュメントによると、`useEffect` は2つの引数を受け取る...
Source: ctx7 /facebook/react

# 悪い回答
useEffect は2つの引数を受け取る...（出典なし）
```

## 要注意事項

### バージョン固有の挙動
バージョン間の破壊的変更に注意。バージョンを明記する。

### 最近の変更
最近追加/削除された機能は WebSearch で確認する。

## セルフチェック

```
□ APIシグネチャを検証したか？
□ バージョンを明記したか？
□ ソースを引用したか？
□ 信頼度レベルを宣言したか？
□ 詳細を捏造していないか？
```
