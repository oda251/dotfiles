**タスクファイルのステータス更新は after-task と plan のみが行う。**

## 手順

### 1. 完了タスクのステータス更新

完了したタスクを `🔵` → `✅` に更新する。

### 2. 現タスクファイルの確認

現タスクファイルに未完了タスク（⬜）が残っているか確認する。

- **残っている** → 次の未完了タスクの種別に応じてスキルを呼ぶ:
  - `plan-*` → **plan**
  - `exec-*` → **exec**

### 3. 親タスクへの復帰

現タスクファイルの全タスクが ✅ の場合:

1. 親タスクファイル（frontmatter の parent）の対象タスク（parent-phase + parent-task）を `🔵` → `✅` に更新する
2. 親タスクファイルに未完了タスクがあれば、次の未完了タスクの種別に応じてスキルを呼ぶ

### 4. ルートタスクの完了判定

親タスクファイルがない（root）場合:

- 全タスクが ✅ → ゴール達成をユーザーに報告する
- 未達成の要件がある → 追加タスクを生成し、適切なスキルを呼ぶ
