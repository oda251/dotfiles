# 職務経歴書 編年体形式フォーマット

## 編年体形式とは

職歴を時系列順（古い→新しい）に記載する形式。キャリアの成長過程が伝わりやすい。
経験年数が浅い人（1〜3年）・初転職・キャリアチェンジ組に最適。

逆編年体は新しい→古い順で、直近の実績をアピールしたい経験豊富な人向け。

## 構成・セクション順序

1. **タイトル**（「職 務 経 歴 書」letter-spacing: 1em、中央揃え）
2. **日付**（右寄せ、「20XX年XX月XX日現在」）
3. **【経歴要約】**（3〜4行。経歴全体を簡潔に要約）
4. **【職務内容】**（編年体＝時系列順）
   - 会社ヘッダ: □20XX年XX月〜現在　○○株式会社
   - 会社メタ: 事業内容：○○　従業員数：○名
   - 期間 / 業務内容の2カラムテーブル（罫線付き）
     - 期間列: 開始年月〜終了年月（縦書き風に改行）
     - 業務内容列:
       - ◆プロジェクト名
       - ◆業務内容（概要文）
       - 【注力した業務】箇条書き（・で列挙、具体的な施策・取り組みレベルで統一）
       - 【技術】使用技術を列挙（遷移は書かない）
       - 【自発的な改善】あれば記載（・で列挙、数値で示す）
5. **【活かせる経験・スキル】**（カテゴリ / スキル の2カラムテーブル、年数は書かない）
6. **【学歴】**（・で列挙）
7. **【資格・活動】**（・で列挙）
8. **【自己PR】**（●強みタイトル + 本文の繰り返し、2〜3点）

## スタイル指針

- 白黒ベースのビジネス文書（背景色・装飾なし）
- テーブルは黒罫線、ヘッダ背景なし
- セクション見出しは【】で囲む
- A4で2枚以内に収める
- 成果は数値で示す（○%短縮、○件など）
- スキル欄に経験年数は書かない（プロジェクト経歴から読み取ってもらう）
- 技術欄に遷移（→）は書かない
- 表記は「BtoC」「BtoB」で統一

## 印刷時の注意

- ブラウザ印刷時「ヘッダーとフッター」のチェックを外す（パス表示を消すため）
- テーブルは行単位で改ページ制御（テーブル全体のpage-break-inside: avoidは使わない）
