# Skill ポリシー

Claude Code skill ファイル（SKILL.md および `references/`）の書き方ルール。

## セルフチェック

セルフチェックには how（手順）を書かない。成果物に対するチェックのみ書く。

## `!`command`` によるシェルコマンド出力の動的埋め込み

- SKILL.md では `!`command`` 構文でシェルコマンド出力を動的に埋め込める。条件を満たす場合は静的に書くより優先する
- ただし `!` 構文は Claude Code 固有。skills は routes.txt で Codex / Cursor にも同一配布されるため、他プロバイダではコマンドが実行されず**リテラル文字列としてコンテキストに残る**
- 使用基準（マルチプロバイダ配布される skill）:
  - 他プロバイダで「コマンド文字列がそのまま指示として読まれる」劣化が許容できる場合のみ使う（例: `ls` によるファイル候補の列挙 → 他プロバイダでは「このコマンドで確認せよ」という指示として機能する）
  - skill 読み込みのたびにネットワーク I/O や重い処理が走るコマンドは埋め込まない（例: `gh api` 系）
  - どちらかを満たせない場合は静的に書く
