# NDC（日本十進分類法）

docs skill の `ndc/*` タグ用語彙。日本十進分類法の 3 桁コードで付ける。

## 一次区分（必ずどれかに該当）

| slug | NDC | 分野 |
|---|---|---|
| `ndc/000` | 000 | 総記 |
| `ndc/100` | 100 | 哲学 |
| `ndc/200` | 200 | 歴史 |
| `ndc/300` | 300 | 社会科学 |
| `ndc/400` | 400 | 自然科学 |
| `ndc/500` | 500 | 技術・工学 |
| `ndc/600` | 600 | 産業 |
| `ndc/700` | 700 | 芸術 |
| `ndc/800` | 800 | 言語 |
| `ndc/900` | 900 | 文学 |

## よく使う 3 桁細目（参考）

| slug | NDC | 内容 |
|---|---|---|
| `ndc/007` | 007 | 情報科学 |
| `ndc/159` | 159 | 人生訓・処世 |
| `ndc/336` | 336 | 経営管理 |
| `ndc/547` | 547 | 通信工学 |
| `ndc/548` | 548 | 情報工学 |

可能なら 3 桁の細目まで降りる。迷ったらトップレベル（`ndc/000` 等）で可。

参考: 日本図書館協会「日本十進分類法新訂10版」が公式の最新版（オンラインで全体表は無償公開されていない）。
