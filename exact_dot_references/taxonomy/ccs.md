# ACM CCS トップレベルカテゴリ

docs skill の `ccs/*` タグ用語彙。ACM Computing Classification System (CCS) 2012 のトップレベル 13 区分に準拠。

| slug | CCS 公式名 | 主な含意 |
|---|---|---|
| `ccs/general` | General and reference | 総論・参考文献・サーベイ |
| `ccs/hardware` | Hardware | 電子回路・VLSI・組込みハードウェア |
| `ccs/systems` | Computer systems organization | アーキテクチャ・並列/分散・組込みシステム |
| `ccs/networks` | Networks | プロトコル・ネットワーク設計・無線/有線通信 |
| `ccs/software` | Software and its engineering | プログラミング言語・SE 方法論・実装技術 |
| `ccs/theory` | Theory of computation | 計算理論・アルゴリズム・複雑性 |
| `ccs/math` | Mathematics of computing | 離散数学・確率・最適化・数値解析 |
| `ccs/info-systems` | Information systems | DB・データ管理・IR・Web アプリ |
| `ccs/security` | Security and privacy | セキュリティ・暗号・プライバシー |
| `ccs/hci` | Human-centered computing | HCI・UI・アクセシビリティ・協調作業 |
| `ccs/methods` | Computing methodologies | AI/ML・モデリング・シミュレーション |
| `ccs/applied` | Applied computing | 業務ドメイン応用（医療・金融・教育・芸術等） |
| `ccs/social` | Social and professional topics | 倫理・法・教育・キャリア・職業 |

トップレベルのみを使う。下位カテゴリ（CCS の 2 階層目以降）は付けない。

参考: ACM CCS 2012 は ACM Digital Library 上で公開されている分類体系（ボットブロックにより自動取得は不可。手元のブラウザで `dl.acm.org/ccs` または `acm.org/publications/class-2012` を参照）。
